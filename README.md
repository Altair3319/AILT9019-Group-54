# AILT9019-Group-54
This is our first version of assistant, it haven't attached any LLM yet. It can only be used to answer the simple question about library regulations with original text citation. How it currently work is that it checks several keywords from users input, and gives the output and cited text according to 'Regulation.docx' and users input. There are some safe refusal case. For example, if user uses any languages except English as input, the assistant will refuse to answer. Also, if there are some keywords like 'real time', 'right now', or 'is ... available', the assistant will also refuse to answer. In the next few weeks, we will keep working on to deal with the weakness of this assistant.
